# Three demonstration scenarios

Select astronaut and mission day using the crew control in the top bar. All values below come from the included fictional scenarios.

## A. Day 45 fatigue
1. Use AST-02, Day 45. Select General Health → Fatigue and begin.
2. Answer No to warning signs, Today for onset, and No for a recurring concern.
3. Enter resting heart rate **72.8 bpm**, sleep **5.47 h**, and fatigue **7/10**. Open **How to measure** to show the source-linked instructions.
4. Select **View results**. Point out the flagged pattern, entered readings alongside baseline means, the NASA sleep and schedule research, and crew review guidance. Open Health history to show the saved assessment and selectable charts.

## B. Cardiovascular
1. Set AST-03, Day 49. Select Cardiovascular → Palpitations.
2. Use No, Today, No for screening, onset, and recurrence.
3. Enter **71.6 bpm**, **7.09 h**, and **123/75 mmHg**. Finish the assessment.
4. Show the actual statistical result, cardiovascular research, and crew review guidance. The two BP readings are recorded for context. The trained model uses heart rate and sleep.

## C. Emergency escalation
1. Set AST-01, Day 60. Select Cardiovascular → Chest discomfort.
2. Answer Yes to the first warning-sign question. This reproduces the warning sign in `ASM-EMERGENCY-DEMO`.
3. SALUS immediately routes to Emergency Assistance and saves an escalated session. Show that no measurements, model result, or research lookup are required.
4. The imported scenario is also available in the Day 60 assessment history. The app identifies the absence of verified onboard procedures.
